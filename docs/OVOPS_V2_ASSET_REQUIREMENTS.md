# OVOPS V2｜素材与脱敏要求

当前所有素材均为 `PENDING_APPROVAL`，未获明确证据前不得当作 OWNED、LICENSED 或 CLIENT_APPROVED 使用。

| 页面/用途 | 所需素材 | 状态与规范 |
| --- | --- | --- |
| 品牌/首页 | 中英深浅 Logo、favicon、OG/微信分享图 | `OWNED` 或书面品牌授权；PNG/SVG/WebP；记录 1:1 与 1200×630 版本 |
| 首页/案例卡 | 每案例桌面、移动、流程图、状态说明 | `CLIENT_APPROVED` 后方可用；优先脱敏示意图 |
| 案例详情 | 首页、后台、流程、交付物成果类型 | 不得暗示上线或客户关系；文件名含 case-id、尺寸、日期、授权状态 |
| About | 创始人、团队、办公、会议/白板 | 人员肖像与办公场景需书面许可；无许可用中性占位 |
| 服务/行业 | 过程图、结构示意、非客户数据图 | `OWNED`/`LICENSED`，alt 描述功能而非未证实结果 |

## 文件与 alt 约定

`{page}-{subject}-{locale}-{variant}-{YYYYMMDD}.{webp|png|svg}`。每项登记：页面、尺寸、格式、压缩后大小、授权、脱敏、中文/英文 alt、来源与复审日期。

## 必须脱敏

姓名、电话、邮箱、客户公司、订单、金额、业务数据、浏览器账号、后台域名、API Key/token、服务器信息、内部备注均须移除或遮盖；只保留功能结构、界面逻辑、模块布局或成果类型。截图原件不得进公开仓库或公开包。
