# OVOPS V1 Static Website

OVOPS V1 is a static local website baseline for enterprise AI solution discovery. It contains the homepage, Solutions overview, six Solution Detail pages, ten Industry Detail pages, and the responsive Industry Rail interaction.

## Status

- Current baseline: Phase 3.12.4 Industry Rail responsive interaction.
- Current phase: Phase 3.13 Canonical Sitemap Completion.
- Completed locally: static source, structural route checks, and the independently verified Industry Rail browser QA scope.
- Not represented by this repository: preview deployment, production deployment, or user acceptance.

## Technology

Static HTML, CSS, vanilla JavaScript, and a Node.js structural check.

```sh
npm run check
npm run preview
```
